# MIRAGE Run Records

- `receipt/`: deterministic receipt-condition records generated by `run_pilot.py`.
- `raw/`: preserved invalid `raw-v1` calibration records. Excluded from headline measurements.
- `raw-v2/`: fixed-prompt hidden-oracle raw-agent trials, including prompt, output, timestamp, model metadata, and command count.
- `raw-v3/`: generic-prompt hidden-oracle calibration records. They measure disagreement with a hidden receipt oracle, not false acceptance, because the evaluator was not given a public exact-reproduction contract.
- `summary/`: generated aggregates of preserved run records. Labels are relative to the recorded receipt outcome and do not independently establish scientific error.

Generated records are evidence. Do not edit them by hand. Regenerate after protocol changes and retain prior records.
